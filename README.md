# 基于STM32的轮式智能送药机器人

面向医院场景的智能药品配送机器人，基于STM32主控实现环形赛道循迹、多站点识别、人机交互与蓝牙遥控功能。

## 功能概述

- 环形赛道循迹，通过左右两侧红外对管识别赛道黑线，阈值判断 + PWM差速控制实现稳定循迹
- 多站点识别，通过左右两侧黑块组合标记区分起点/药房/病房站点
- 6键人机交互面板（药品上下翻选/确认 + 目标病房选择）
- OLED实时显示药品列表与配送状态
- 蓝牙透传，支持手机APP遥控与手动/自动模式切换
- 语音播报，到达站点或遇障时触发语音提示
- 避障功能，遇障停车并播报提示，障碍清除后自动恢复

## 目录结构

- User/ - 主程序与中断服务
- Hardware/ - 各模块驱动（电机/循迹/避障/OLED/蓝牙/语音/按键）
- Library/ - STM32标准外设库
- Start/ - 启动文件与系统初始化
- System/ - 延时等系统工具

## 技术栈

- 主控：STM32F103C8T6
- 开发环境：Keil5、C语言
- 外设驱动：PWM电机驱动、红外循迹/避障传感器、UART通信（蓝牙透传）、I2C协议（OLED驱动）、GPIO中断（按键检测）
- 通信协议：自定义串口指令协议

## 运行说明

1. 使用 Keil5 打开 Project.uvprojx
2. 编译并下载到 STM32F103C8T6
3. 上电后小车自动进入待机状态
4. 通过按键或手机APP控制配送流程
